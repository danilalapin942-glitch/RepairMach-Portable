RepairMach 9.1
==============

Это публичная beta-сборка версии 9.1. Она объединяет три расчётных контура:

1. MachLine — волновое и потенциальное обтекание.
2. VSPAERO — подъёмная сила и индуктивное сопротивление.
3. OpenVSP Parasite Drag — трение и сопротивление формы для дозвуковых режимов.

Запуск
------
Запустите RepairMach.bat.

Состав версии 9
---------------
- импорт, диагностика и безопасное исправление TRI;
- создание входных JSON и запуск MachLine;
- импорт VSP3 и автоматический запуск VSPAERO после проверки Set_1/Set_2;
- каталог готовых сценариев в функции [9];
- исполняемые сценарии диагностики, быстрой оценки, дозвуковой, сверхзвуковой и полной АДХ;
- сценарий расчёта с заданным углом GO;
- протоколы сеточной сходимости, ночного расчёта и верификации;
- проверка имён Wing, Fuselage, GO, VO и Gondola;
- дополнительный заданный балансировочный угол горизонтального оперения;
- ручной запуск готовых сценариев OpenVSP/VSPAERO;
- расчёт дозвукового паразитного сопротивления средствами OpenVSP;
- формирование прозрачного гибридного отчёта;
- явный ввод опорной площади, длин и центра масс для каждого самолёта;
- отсутствие постоянной калибровочной добавки к C_D.

Ограничения
-----------
- OpenVSP 3.51 должен оставаться установленным на этом компьютере;
- Parasite Drag применяется только при M < 1;
- для сверхзвука расчёт трения и формы требует отдельной модели;
- результаты ночного исследования намеренно не включены — они предназначены
  для версии 10 после проверки.

Подробности находятся в README.md и CHANGELOG_9.md.
