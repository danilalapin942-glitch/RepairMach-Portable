# Дневной аудит расчёта Cx0 МиГ-25РБ, M=1,2

Дата: 5 сентября 2026 г.

## Итог

Достоверное значение Cx0 не получено. Контрольная точка α=0° не удовлетворила обязательному критерию `residual_norm <= 1e-5`, поэтому точки α=-1° и +1° не запускались и интерполяция при Cnormal=0 не выполнялась.

Исходный файл `C:\MiG-25\MiG-25_Gondola_ML_MeshFix02.vsp3` не изменялся. Все проверки выполнены только на расчётных копиях сетки. Книжная кривая не использовалась для настройки решения.

Во всех принятых к запуску расчётных сетках аудит показал отсутствие superinclined-панелей. Следовательно, текущий отказ не объясняется выбором решателя, смещением контрольных точек, асимметрией или единичной недопустимой панелью.

## Установленная причина

Проблема связана с геометрическим представлением задней части Fuselage–Gondola. В текущей CFD-сетке каждая гондола заканчивается Point-замыканием. Для открытия сопел приходится удалять по 243 треугольника замыкания, после чего остаются два сложных выходных контура по 51 ребру. Такая постановка даёт плохо обусловленную либо вырожденную систему MachLine.

Для сравнения, ранее сходившаяся сетка имела плоские съёмные крышки: удалялось всего 74 плоских панели, а M=1,2, α=0° сходилась до `residual_norm=5,13e-9` при той же постановке Morino/FQRUP и local offset 1e-4. Это независимое подтверждение, что отказ вызван способом построения выхода, а не физической моделью или параметрами решателя.

## Требуемая правка OpenVSP

1. На обеих Gondola убрать заднее Point-замыкание.
2. Последнее поперечное сечение поставить точно в плоскости среза сопла; не сводить его к точке.
3. Выбрать плоское заднее замыкание (`Aft Cap Type = Flat`) либо эквивалентную единственную плоскую крышку.
4. Сохранить боковую поверхность гондолы до плоскости среза без узких переходных секций.
5. Обеспечить осознанное пересечение с Fuselage: небольшой устойчивый нахлёст лучше касания или почти совпадающих поверхностей.
6. После CFD Mesh удалить только плоские крышки сопел, не удаляя боковые панели и панели стыка.
7. Проверить, что каждый выход образует один чистый замкнутый контур без ветвлений и мелких фрагментов.

После новой сетки порядок проверки остаётся прежним: аудит топологии → отсутствие superinclined-панелей → M=1,2, α=0° → только затем α=±1° → интерполяция Cx при Cnormal=0 → независимое сравнение с книгой.

## Книжное сравнение

Не выполнялось, поскольку ни одна новая расчётная точка не прошла численный критерий достоверности. Сравнивать книжный Cx0 с несошедшимся решением было бы некорректно.
