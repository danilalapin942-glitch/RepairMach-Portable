# Независимые ветки сертификатора

Реализовано 26.09.2026. Один неизменяемый MASTER, отдельные расчётные копии,
пакеты доказательств, сертификаты и указатели последних результатов.
Это независимость постановок, а не обязательный одновременный запуск двух
ресурсоёмких процессов.

## Штатное меню

В меню [9] «Расчётные сценарии»:

- [17] `vspaero_independent_certification`: VSPAERO mixed/lifting и существующая
  лестница сеточной сходимости. Не создаёт MachLine-двойник, не экспортирует TRI
  для MachLine и не запускает MachLine. Выводы: `11_cert_vspaero`.
- [18] `machline_open_nozzle_certification`: отдельная подготовка толстотельной
  расчётной сетки с явно объявленными открытыми соплами, аудит остальных границ,
  геометрический Mach-критерий, реальные угловые пробы, маска сил и вывод
  давления по точкам. VSPAERO-пробы не запускаются. Выводы: `11_cert_machline`.
- Старый [13] остаётся совместимым комбинированным маршрутом с закрытым
  толстотельным MachLine-двойником. Открытые сопла в этот маршрут не подмешиваются.

Последние результаты веток сохраняются в `11_geometry_certification` как
`latest_vspaero_certificate.json` / `latest_machline_certificate.json`.
Отказы имеют отдельные имена с `failed_`. Общий прежний указатель и старые
пакеты не перезаписываются. Штатный выбор расчётной геометрии сначала проверяет
сертификат нужного решателя и совпадение SHA-256 MASTER; ошибочный сертификат
не заменяется исходной моделью молча. Повтор корректирующего плана сохраняет
ветку исходного сертификата.

## Открытие сопла

Крышка удаляется **при подготовке TRI к MachLine и его численным пробам**,
а не в MASTER и не в VSPAERO-копии. Фюзеляж автоматически не открывается.
Открытая гондола — не глобальное разрешение отверстий.

Первая реализация работает с осевым плоским терминальным срезом по X в
координатах NASCART (экспорт OpenVSP XYZ → X,Z,-Y). Указывается точное имя
экспортированной поверхности и абсолютный X сечения в единицах экспорта.
Имена берутся из `component_map` манифеста экспорта, не угадываются по
самому длинному телу. Повторяющееся/неоднозначное имя блокирует удаление.

Параметры проекта:

```json
{
  "geometry_certification": {
    "branches": {
      "machline_open_nozzle": {
        "policy_overrides": {
          "machline": {
            "open_nozzles": [
              {"component_name": "EXACT_EXPORTED_OUTLET_SURFACE", "plane_x": 123.45}
            ]
          }
        }
      }
    }
  }
}
```

Это пример структуры, **не параметры MQ-20**. Значения нельзя копировать в
рабочий проект. Поля `scope_override` и `policy_overrides` в записи ветки
заменяют одноимённые общие поля целиком: при необходимости перенесите в них
все одобренные настройки проекта. Глобальные допуски автоматически не меняются.

Перед удалением проверяются ориентация, положение среза и суммарная площадь
крышек (не более 5% Sref). После удаления проверяются один замкнутый контур
граничных рёбер на каждый выход, отсутствие других дыр и дефектов топологии.
Неиспользуемые вершины удалённых крышек исключаются из TRI. Координаты
сохранившихся физических вершин не сдвигаются. Уже открытый правильно
объявленный выход проверяется без дополнительного удаления.

`machline/open_nozzle_audit.json` содержит исходные номера удалённых граней
в подготовленной толстотельной сетке, соответствие вершин, площади и контуры.
Финальная сетка, маска сил, журнал и пробы входят в пакет доказательств с
хэшами. Superinclined-аудит использует сохранившиеся панели, не удалённую крышку.

## Границы допуска

Указанное в документации MachLine условие открытого сопла относится к
сверхзвуковой постановке: выход должен быть позади остальной геометрии по
потоку. Проверка учитывает заявленные alpha/beta и весь самолёт.
Источник: https://github.com/usuaero/MachLine/wiki/Modeling

**Дозвуковая постановка открытого сопла в этой ветке пока не квалифицирована.**
При области, содержащей M≤1, она не выдаёт PASS и не запускает неподдерживаемые
численные пробы. Действие — разработка/валидация метода, а не автоматический
повтор, изменение Mach или порога невязки. Это не мешает отдельно считать
дозвук VSPAERO.

Положительный MachLine-сертификат распространяется только на реально
проверенные точки и маскированную pressure/wave-составляющую толстых тел.
Он не подтверждает полный самолётный Cx0, вязкость, донное сопротивление,
аэродинамическую точность 5% или сеточную сходимость полной АДХ.
Тонкие поверхности остаются задачей VSPAERO. Сертификат одной ветки не
выдаёт допуск другой и не разрешает автоматически их гибридную сборку.

Автоматическое восстановление входного конуса по Engine Definition и
распознавание выходных станций из Design — отдельное будущее расширение;
эта реализация использует явное объявление осевого выходного среза.
