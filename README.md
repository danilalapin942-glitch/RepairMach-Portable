# RepairMach Portable

RepairMach 9.1 — переносимый Windows-комплекс для подготовки геометрии и
воспроизводимого расчёта аэродинамических характеристик с помощью OpenVSP,
VSPAERO, MachLine, OpenVSP Parasite Drag и заранее объявленных
полуэмпирических слагаемых.

> Статус: экспериментальная beta-версия. Сертификат геометрии подтверждает
> целостность расчётного тракта, но не является гарантией совпадения с
> продувкой. Перед инженерным использованием проверяйте сходимость, невязки,
> физическую полноту и независимые данные.

## Что автоматизировано

- переносимый Python и локальный запуск MachLine;
- обнаружение OpenVSP/VSPAERO и среды построения Excel;
- проектная структура с отдельным хранением MASTER, сеток, результатов и
  журналов;
- диагностика TRI, консервативный ограниченный ремонт и сверхзвуковой
  Mach-критерий;
- готовые дозвуковые, сверхзвуковые и объединённые сценарии VSPAERO;
- фиксированный угол горизонтального оперения и независимые сверхзвуковые
  точки с `To Face` для `Gondola*`;
- автоматическая сертификация геометрии G0–G8;
- покомпонентный контракт покрытия MachLine/VSPAERO/Parasite Drag: отчёт
  решателя не может заменить деталь, которой нет в его сертифицированной сетке;
- неизменяемый MASTER, запечатанный PLAN и отдельные двойники для
  mixed/lifting VSPAERO, MachLine и Parasite Drag;
- три обязательных уровня `Coarse/Medium/Fine`, условные проверочные
  `ExtraFine/UltraFine` и 15 квалификационных точек;
- автоматическая изоляция проблемной компонентной группы при нечисловом
  отказе VSPAERO без изменения производственной геометрии;
- автоматический экспорт MachLine TRI из Fine-двойника через OpenVSP NASCART;
- строгая проверка расчётных выходов и их происхождения: полная сетка
  `Mach–alpha`, конечные коэффициенты, невязки, статусы и SHA-256 файлов и
  исполняемых модулей;
- компонентный дозвуковой OpenVSP Parasite Drag;
- автоматическая гибридная сборка MachLine + VSPAERO + Parasite Drag +
  разрешённая полуэмпирика;
- обязательный паспорт активной полуэмпирики: метод, версия уравнения,
  применимость, неопределённость, независимый источник и при наличии файла его
  SHA-256;
- единый JSON/CSV/XLSX с `Cx0`, `Cy`, `Cyα(M)`, RSS/консервативной
  неопределённостью полуэмпирических добавок и графиками, связанными только с
  внутренними ячейками книги;
- Excel содержит отдельный паспортный реестр полуэмпирики: область Mach,
  `method_id`, версию уравнения, источник, SHA-256 доказательства и отпечаток
  применённого члена;
- слепая верификация с запечатыванием входов и прогноза до раскрытия эталона.

## Быстрый путь оператора

1. Распакуйте комплекс, предпочтительно в `C:\RepairMach-Portable`, и
   запустите `RepairMach.bat`.
2. Выберите `[1] Проверить среду`. Должны быть найдены Python, MachLine,
   `vspscript.exe`, `vspaero.exe` и средство построения Excel.
3. Создайте проект `[2]` или выберите существующий `[3]`. Укажите документально
   обоснованные `Sref`, `cref`, `bref` и `CG X Y Z` в единицах VSP3.
4. Подготовьте окончательный MASTER: точные основные имена `Wing` и
   `Fuselage`; `GO`, `VO*`, `Gondola*` по необходимости; толстые тела в
   пользовательском `Set_1`, тонкие несущие поверхности в `Set_2`.
5. Откройте `[9]` и выберите сценарий `[13]` «Автоматическая сертификация
   геометрии VSP3». На запрос старого TRI обычно нажмите Enter: для MachLine
   программа сама экспортирует TRI из собственного Fine-двойника. Переданный
   TRI служит только дополнительной исторической подсказкой и не заменяет
   подтверждённый экспорт.
6. Принимайте только целый `certificate.json`. Проверьте вердикт,
   `backends.<name>.eligible`, область, `eligible_scenarios`, режим
   mixed/lifting и флаг `hybrid_substitution_required`.
7. Запустите контрольный сценарий `Cyα`, затем нужную серию VSPAERO. RepairMach
   сверяет не только ID, но и SHA-256 полного содержимого сценария,
   автоматически выбирает записанный Fine-двойник и блокирует опорные величины.
   Изменение cases, GO, beta или `engine_boundary` требует пересертификации.
8. Выполните MachLine по `certified_mesh.tri`, указанному в сертификате, и
   Parasite Drag `[10]` для каждой требуемой дозвуковой скорости.
9. Соберите результат пунктом `[11]`. Укажите манифест VSPAERO, каталог
   отчётов MachLine, каталог манифестов Parasite Drag, гибридную политику и
   сертификат. Программа проверит происхождение источников и построит Excel.
10. Для реальной независимой проверки до просмотра эталона создайте пакет
    пунктом `[14]`, после расчёта запечатайте JSON/CSV/XLSX, и лишь затем
    подключайте эталонные данные.

Полная инструкция оператора и вся расчётная методика находятся в
[`USER_GUIDE_AND_METHOD.md`](USER_GUIDE_AND_METHOD.md). Детали G0–G8 и
контракта сертификата — в
[`GEOMETRY_CERTIFICATION.md`](GEOMETRY_CERTIFICATION.md). Правила слепой
проверки — в [`BLIND_VALIDATION.md`](BLIND_VALIDATION.md).

## Главное меню

| Пункт | Назначение |
|---:|---|
| `[1]` | проверка среды |
| `[2]`, `[3]` | создание и выбор проекта |
| `[4]`, `[5]` | импорт и диагностика TRI |
| `[6]`, `[7]` | создание задания и запуск MachLine |
| `[8]` | ручной диапазон VSPAERO |
| `[9]` | готовые сценарии, включая сертификацию `[13]` |
| `[10]` | OpenVSP Parasite Drag для `0 < M < 1` |
| `[11]` | гибридная сборка и Excel |
| `[12]` | открыть папку проекта |
| `[13]` | расширенный ручной запуск `.vspscript` |
| `[14]` | слепая верификация |

Номер `[13]` внутри списка `[9]` — сценарий сертификации; `[13]` главного
меню — другая, ручная функция.

Пункт `[8]` не наследует сертификат: произвольные интерактивные Mach, alpha и
GO считаются на выбранном MASTER и явно маркируются
`НЕСЕРТИФИЦИРОВАННЫЙ ЗАПУСК`. Для сертифицированной цепочки используйте
неизменённый сценарий из `[9]`.

## Основные правила

- `Wing` и `Fuselage` должны существовать ровно по одному разу. Повторные
  компоненты именуются суффиксом, например `VO_upper`, `Gondola_L`.
- В интерфейсе OpenVSP пользовательские `Set_1`/`Set_2` соответствуют
  API-индексам 4/5; RepairMach выполняет это преобразование.
- Неизвестные имена, неоднозначные aliases, пустые/пересекающиеся Sets и
  неверный тип тонкой поверхности блокируют сертификацию.
- Исключение компонента допускается только точной декларацией с
  `backends: ["vspaero", "hybrid"]`, причиной и каноническим
  `replacement_required`. Молчаливое исключение запрещено.
- Полный профиль G7 содержит 15 anchors; каждый решается как минимум на
  Coarse, Medium и Fine. Пограничная точка автоматически получает ExtraFine,
  а при необходимости UltraFine; производственной остаётся Fine. Обязательны
  конечные `CLtot`/`CDi`/`CDtot`, точное соответствие режиму,
  здоровый журнал и для любого `M > 0` — `log10(L2) <= -0.3`. В строго
  нулевой точке VSPAERO 3.51 не печатает конечную невязку, поэтому она может
  пройти только по полной сеточной сходимости при отсутствии иных ошибок.
- Промежуточные NaN нормировки нулевой правой части допускаются только при
  `alpha=beta=0`, точном `CLtot=0`, конечной итоговой невязке и чистом журнале;
  любой NaN в результате остаётся blocker.
- Гибрид повторно вычисляет качество VSPAERO по фактическим POLAR и log.
  Манифест может потребовать значение строже `-0.3`, но не может ослабить этот
  абсолютный верхний предел.
- Для каждой величины сохраняются знаковые изменения Coarse→Medium и
  Medium→Fine, признаки `monotonic`/`oscillating` и отношение сжатия изменений.
  Допуск по-прежнему относится к Medium→Fine: не более 5% либо `0,005` для
  `CLtot` и `0,0005` для `CDtot`. Большой шаг Coarse→Medium сам по себе не
  запрещает результат. Смена знака значимых шагов вызывает следующий
  проверочный уровень; шум меньше 10% абсолютного допуска не считается
  разрешимой осцилляцией, а сохранённая значимая осцилляция блокирует точку.
- Транзвуковой интервал `M=0,9…1,1` не создаётся автоматически: используемые
  панельные методы не моделируют всю реальную транзвуковую физику.
- MachLine не заменяет вязкий CFD. Parasite Drag применяется только при
  `0 < M < 1`. Полуэмпирические члены объявляются до просмотра эталона и не
  экстраполируются вне своей области.
- При сложении MachLine и `VSPAERO CDi` проверяйте состояние следа, чтобы не
  посчитать индуктивный вклад дважды.
- Численный предел 5% — не обещание 5% относительно продувки. Принятый
  ориентир средней суммарной ошибки после слепого раскрытия — 11%; отдельная
  точка имеет целевой коридор 15% и жёсткий предел 20%.
- Близость к книжной/продувочной кривой не участвует в выборе сетки, решения
  или поправки. Любая методическая правка после раскрытия эталона образует
  новый прогноз.
- Excel публикуется только после проверки формул, числовой оси Mach,
  внутренних ссылок серий и отсутствия внешних связей.
