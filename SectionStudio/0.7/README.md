# Section Studio 0.7.0

[Скачать исходный архив](Fuselage_Section_Studio_v07.zip?raw=true).

Распакуйте ZIP и откройте `Section_Studio.html` в Chrome, Edge или Firefox.
Полная инструкция: [README.txt](README.txt). Исходники: [source](source).
OpenVSP нужен для проверки и использования экспортированной геометрии;
`Run_OpenVSP.bat` запрашивает путь к установленному OpenVSP.

Выпуск добавляет вкладку «Библиотека сечений» с 75 шаблонами семи ранее
созданных моделей. Все 20 файлов предоставленного архива сохранены без изменений.

SHA256 оригинального ZIP:
`aaf97608806bf29091b084873bfaf5283497e97c773c3a36f8104a9c25c7008b`.

## Проверки перед публикацией

Независимо выполнены проверка CRC и байтов 20 файлов, разбор JSON и XML VSP3,
сверка готового HTML со сборкой исходников, проверка синтаксиса JavaScript,
472 программные проверки, в том числе всех 75 шаблонов и сохранения параметров
при применении. Проверка потенциальных секретов не выявила совпадений;
вызовов сетевого обмена в скриптах не найдено.

Подробности и хэши: [publication_verification.json](publication_verification.json).
[Validation.json](Validation.json) — исходный отчёт автора о браузерных и
OpenVSP-проверках; эти проверки при публикации повторно не запускались.
Аэродинамический решатель не запускался.

## Ограничения

Редактор и его предварительная геометрическая диагностика не заменяют проверку
окончательной поверхности и сетки в OpenVSP. Пространственные пересечения
наклонных сечений, двигательные обрезки и проточные каналы полностью не проверяются.
Примеры и библиотека представляют модельные формы, не подтверждённые заводские
обводы. Наличие примеров с диагностическими предупреждениями не является
свидетельством их физического допуска.
