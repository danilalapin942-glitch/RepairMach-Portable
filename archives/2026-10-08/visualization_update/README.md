# Обновление вывода давления, 08.10.2026

После каждого штатного вызова VSPAERO сохраняются отдельные VTU по режимам,
сцена ParaView и точный нативный набор ADB + ADB.cases для Viewer OpenVSP.
Каждый набор связан с режимом, источниками и контрольными суммами. Неполные
результаты явно недоступны; поля непринятых расчётов маркируются диагностическими.
Окна во время серии сами не открываются — используются запускатели и пункт [15].

Для MachLine сохраняется исходный VTK без изменения полей. Читается полный
ASCII POLYDATA, проверяются сетка, индексы, размеры и конечность массивов.
Viewer не поддерживает MachLine VTK: это явно отражено, фиктивный ADB не создаётся.

325 тестов прошли на stage и в checkout, 323 — в установленном комплексе;
ещё два относятся только к переносимой конфигурации. Настоящий
ParaView 6.1.1 прочитал и отрисовал синтетические сцены; нативные сохранённые
ADB/VTK проверены экспортом без новых аэродинамических расчётов. Протокол
Viewer проверен по официальным исходникам OpenVSP_3.51.0 и контрольным
запуском аргументов (без открытия GUI Viewer). Это проверка программного вывода,
не физическая приёмка расчёта или сертификат.

Патч установлен с резервной копией `visualization_output_20261008_153250`.
Восемь файлов обновлены точечно; модели, конфигурация, решатели и исходные
свидетельства не менялись. 83 защищённых файла отдельно сверены по SHA256.
Старое открытое меню комплекса нужно переоткрыть, чтобы загрузить обновлённые модули.

`code_update.zip` и `update_manifest.json` содержат только эти восемь файлов.
Основные полные архивы здесь не заменялись: они сохраняют состояние до обновления.
В `evidence/` находятся журналы тестов, хэши, проверка ParaView, план внедрения
и подтверждения сохранности. Перечень текущих возможностей см. в
[инструкции](../../../docs/PARAVIEW_PRESSURE.md).

Подтверждение владельца получено **09.10.2026**. Весь подготовленный набор,
включая это обновление, загружен и проверен в публичном репозитории GitHub:
[датированное подтверждение](../publication_2026-10-09.json).
Прежние manifest и evidence сохраняют исторический статус подготовки;
они не переписывались задним числом.
